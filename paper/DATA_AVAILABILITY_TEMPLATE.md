## Standard unrestricted statement (USE ONLY IF TRUE)
> The minimal dataset necessary to reproduce the analyses, including [explicitly name licensed sample IDs, group-safe split assignments, adjudicated annotations, model predictions, and figure source values], is deposited at [archive DOI]. Analysis scripts and environment specifications are archived at [code release DOI] and available at [GitHub release URL]. Source datasets were originally obtained from [individual source citations and version URLs]. [All redistribution rights and privacy constraints have been verified.]

## Third-party source statement (USE ONLY IF PLOS POLICY PERMITS)
> This study analyzed third-party datasets available from the original providers: [each provider, permanent URL, exact version, accession/DOI, and retrieval instructions]. We do not have permission to redistribute [specific restricted raw content]. The publicly available analysis-specific artifacts consist of [lawfully shareable IDs, de-identified annotations, hashes, splits and derived statistics] at [DOI], and the code required for their reproduction is at [DOI]. The restrictions and how qualified researchers can obtain the underlying original data are [precise published access method].

DO NOT use the second statement unless independent investigators can obtain source data by the same lawful route, and the restriction aligns with journal policy. If PLOS asks for a formally managed ethics/data access committee, obtain it or choose a different openly redistributable dataset.

## Pre-submission checks
- [ ] Sources downloadable or accessible to external researchers on equivalent terms; no source requires a private author-only credential.
- [ ] Copyright and licensing permit the uses and deposited derivatives.
- [ ] Email sender addresses, active phishing URLs, attachments and identifiers are redacted or restricted appropriately.
- [ ] Release includes actual preprocessed/split/label provenance and source revisions, not just aggregate accuracy.
- [ ] All values behind plots, uncertainty intervals, confusion matrices and summary tables are deposited.
- [ ] Code and environment versions support clean rerun; exact model hyperparameters and seeds are provided.
- [ ] Where restrictions exist, details and stable access routes are included in the public statement.
- [ ] Statement uses only verified facts: replace all [pending] and UNKNOWN cells.
- [ ] Check current PLOS data and code policies immediately before submission.
