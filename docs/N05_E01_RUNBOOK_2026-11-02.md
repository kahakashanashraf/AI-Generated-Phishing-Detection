**Status:** Local notebook build, Python syntax check, nbformat validation and synthetic function smoke PASS. **Kaggle execution NOT YET RUN.** The notebook artifact is supplied as a downloadable `.ipynb` in the current chat; this GitHub document is a committed runbook, **not** a claim that its notebook bytes have been pushed.

## Objective
Compare false-positive rates on D2 source-annotated `Valid` original emails and corresponding LLM-rewritten versions from the **same held-out parent ID**. Secondary evaluation on original versus rewritten `Phishing` recall. Compare TF-IDF logistic regression and calibrated linear SVM, with 5% validation-selected FPR threshold.

## Guardrails
- Pin HarmJ0y D2 original, DeepSeek, GPT-4o and RandomAPI files to commit `d13e9bb73d03f458e6d5b6cb6c7b0a708ea47e3d` and verify size and Git blob SHA-1 before parsing.
- Map only source `Phishing -> 1`, `Valid -> 0`. Exclude `Spam`, `Phishing Simulation` and unknown classes; don't mistake AI/human origin for maliciousness.
- Split **original parent IDs** into stratified train/validation/test, seed 2026. All held-out rewrites remain in the test parent group, never train.
- Exclude original records sharing identical normalized subject+body across different parent IDs; suppress held-out rewrite text exactly equal to training text.
- Fit text vectorizer, classifier and probability calibration exclusively on train. Select threshold only on validation. Report both overall held-out and paired same-parent false alarm changes.
- Original labels are source-assigned, not individually adjudicated gold. Rewrites are a conditional robustness probe, not a certified semantic-equivalence set.
- D2 and D3 share almost all parent lineage; **D3 is not an independent external holdout**. D4 is not used in E01 due to generator/language confound.
- No raw email, links, sender addresses, private review aids, row-level model scores or decisions in public outputs.
